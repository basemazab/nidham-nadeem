# حزمة نِظام المحلية (Nidham Local Harness)

بديل آمن لـ ECC. نفس الـ workflow، صفر مخاطر تنصيب.

## قواعد أمان هذه الحزمة

1. **لا توجد hooks إطلاقًا.** ملف settings.json ليس فيه مفتاح `hooks`. لا يوجد أي كود ينفّذ تلقائيًا قبل أو بعد أي أداة.
2. **كل شيء داخل المشروع.** لا شيء يُكتب في `~/.claude` أو `C:\Users\<you>\.claude`. لا تأثير على أي مشروع آخر.
3. **لا auto-update.** لا `git pull`، لا reinstall، لا سكربت تحديث. أنت تعدّل الملفات بيدك فقط.
4. **لا MCP جديد.** هذه الحزمة لا تضيف أي سيرفر MCP ولا تستدعي `npx -y` ولا `@latest`.
5. **صلاحيات صريحة ومحدودة.** كل agent يعلن أدواته. agent واحد فقط له صلاحية Bash، ومحصورة بأوامر الاختبار.
6. **الذاكرة يدوية.** لا يوجد observer يعمل في الخلفية. الذاكرة ملفات Markdown أنت تقرأها وتوافق عليها.

## التنصيب

انسخ مجلد `.claude` كاملًا إلى جذر مشروع nidham. خلاص.

```powershell
# من جذر مشروع نِظام
Copy-Item -Recurse -Force "<مسار-فك-الضغط>\.claude" .
```

ثم افتح Claude Code في المشروع واكتب `/permissions` للتأكد أن الصلاحيات اتفعّلت.

## الاستخدام

| الأمر | يعمل إيه |
|---|---|
| `/plan <المهمة>` | خطة مكتوبة قبل أي كود، ولا يكتب كود إلا بعد موافقتك |
| `/tdd <المهمة>` | اختبار فاشل الأول، بعدين أقل كود يخلّيه ينجح |
| `/review` | مراجعة كود على الـ diff الحالي فقط |
| `/security-check` | فحص أمني مركّز على RLS و multi-tenancy و PII |
| `/verify` | typecheck + lint + tests + قائمة تحقق يدوية |
| `/remember` | يقترح سطور تضاف لملفات الذاكرة — بموافقتك |

## الترتيب المقترح

```
/plan  →  (توافق)  →  /tdd  →  /review  →  /security-check  →  /verify  →  /remember
```

## الصيانة

راجع `.claude/memory/lessons.md` كل شهر واحذف اللي بقى قديم. الملفات دي بتتحمّل في السياق، فكل سطر ليه تكلفة.

# الذاكرة

ملفات Markdown عادية. أنت اللي بتكتبها وبتوافق على كل سطر يتضاف — عن طريق `/remember`.

مفيش أي process بيشتغل في الخلفية، ومفيش agent بيكتب هنا من غير إذنك. ده الفرق الأساسي بين الحزمة دي وبين أنظمة الـ "instincts" اللي بتكتب لنفسها.

## قاعدة مهمة

الملفات دي بتتقري وبتاخد مساحة من السياق. خليها قصيرة.
سطر مش هيفرق معاك بعد شهر = سطر يتشال.

**ممنوع تمامًا هنا:** مفاتيح، توكنز، connection strings، أسماء عملاء، أرقام مرتبات، أو أي بيانات شخصية لموظف أو متقدم لوظيفة.
